# Aero Gallery

A Frutiger Aero picture gallery and toy box, made for Henry to browse on his iPad.

- 98 photos (bubbles, water, sea creatures, lagoons, blue skies, green things, space), all from Wikimedia Commons under free licences. Tap any photo to see its photographer, licence and source page.
- Toys: Bubble Pop, Aquarium, Shiny Orbs, Ripple Pond, Glass Chimes, Cloud Painter.

Edit `src.html`, then run `python3 build.py` to regenerate `index.html` (it inlines `items.json`).
